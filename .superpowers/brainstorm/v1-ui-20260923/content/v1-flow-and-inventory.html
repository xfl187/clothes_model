V1 UI Flow 与 Screen Inventory

先覆盖单件精准换装完整闭环；V1.1 只预留稳定扩展点。

设计原则任务是主线，素材是可复用资源，异常恢复属于任务详情而不是新的孤立流程。后续 V1.1 复用素材选择、Provider 设置、任务状态与结果组件。
01 · 连接与认证首次配置服务器；令牌失效时保留地址并重新认证
02 · 首页精准换装主入口、最近任务、V1.1 预留入口
03 · 创建换装选人物 → 选衣物 → Provider 与候选数 → 确认
04 · 任务执行排队、等待节点、准备、生成；允许离开页面
05 · 候选结果对比、收藏、下载、候选级重试或取消
06 · 修正与留存遮罩编辑创建关联新任务；历史保留执行谱系

首轮关键页面原型：6 组

覆盖主闭环与最高风险恢复场景，不铺开全部 23 个页面。

01 · 首次连接连接验证与重新认证状态
02 · 首页模式入口、最近任务、V1.1 扩展位
03 · 创建向导人物、衣物、设置三步连续体验
04 · 任务详情运行、等待与 needs_attention 状态
05 · 候选结果部分成功、对比与结果操作
06 · 遮罩修正编辑、兼容 Provider 切换与新任务确认
